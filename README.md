# 🌌 NEBULA — 3D Interactive Cosmic Experience

An immersive 3D space experience featuring a mysterious cosmic planet, glowing atmosphere, animated celestial objects, and interactive exploration. NEBULA brings the beauty of deep space to life through a cinematic visual experience built with JavaScript and Three.js.

## 🚀 Live Demo

**Explore NEBULA:** https://tayyaba-codes478.github.io/NEBULA/

## ✨ Features

- Interactive 3D planet
- Animated cosmic atmosphere and glowing effects
- Floating particles and star field
- Orbital rings and energy arcs
- Moon and satellite animations
- Interactive zoom and camera controls
- Mouse-responsive 3D movement
- Smooth animations and cinematic visuals
- Responsive layout
- Optimized rendering for better performance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL

## 🌠 Project Concept

NEBULA is a creative frontend experiment inspired by deep space, distant planets, cosmic energy, and futuristic exploration. The project combines 3D graphics, animations, lighting effects, and interactive controls to create an immersive digital environment.
